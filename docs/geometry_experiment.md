# Bounding-box Geometry Rule 实验记录

已实现报告第 3.1、3.5 节的两种几何规则，并按第 4 节的原则完成验证集选参、固定参数后的测试集评估、逐人体区域预测记录及误差分析。实验使用数据集给定的人体框，不包含人体定位。当前位置变体采用一个明确的假设：框的中心越靠近画面下方，越可能是跌倒姿态；本次结果没有支持加入这一条件。

## 方法与评估单位

宽高比规则使用原始像素坐标中的 `r = w / h`，当 `r > t_r` 时预测 Fall。YOLO 标签的宽、高分别相对于图像宽、高归一化，因此实际计算为：

```text
r = (label_width × image_width) / (label_height × image_height)
```

位置变体使用 `p_y = y_center / image_height`，即标签中的归一化中心纵坐标，判断条件为 `r > t_r AND p_y >= t_y`。0 表示图像顶部，1 表示底部。`t_y = 0` 时，该变体退化为宽高比规则。

每一个 `fall` 或 `up` 标注框是一个评估样本；同一图像中的多人分别评估。Fall 是正类，Up 是 No Fall。`0 person` 框及空标注图像单独导出，不参与人体区域分类，也不增加 TN。当前验证集和测试集没有 `0 person` 标注，因此不报告无人图像误报率。

本方法不需要训练集拟合模型。阈值只使用验证集选择，测试集不参与选择。验证集搜索包含 915 个宽高比阈值、512 个纵向位置阈值，共 468,480 组联合候选，覆盖这些规则在验证集上的不同预测结果。先最大化 Fall F1，F1 相同时选择更高 Fall Recall，再优先选择较低的位置阈值及宽高比阈值。两个方案的验证集 F1 和 Recall 相同时，推荐较简单的宽高比规则。

## 固定参数与结果

验证集选出的宽高比阈值为 `t_r = 0.5128939828080229`。联合规则选出的参数为同一 `t_r` 和 `t_y = 0.0`。推荐方案在读取测试集之前已经保存为 `aspect_ratio`。

| 数据划分 | 图像数 | 人体区域数 | Fall 区域 | Up 区域 |
|---|---:|---:|---:|---:|
| 验证集 | 872 | 929 | 739 | 190 |
| 测试集 | 446 | 471 | 366 | 105 |

| 数据划分 | 方案 | Fall Precision | Fall Recall | Fall F1 | Up 区域误报率 |
|---|---|---:|---:|---:|---:|
| 验证集 | 宽高比 | 95.22% | 94.32% | 94.77% | 18.42% |
| 验证集 | 宽高比与纵向位置 | 95.22% | 94.32% | 94.77% | 18.42% |
| 测试集 | 宽高比 | 91.15% | 92.90% | 92.02% | 31.43% |
| 测试集 | 宽高比与纵向位置 | 91.15% | 92.90% | 92.02% | 31.43% |

两种方案的预测相同。位置阈值没有在验证集上改善所选指标，因此不能据此声称位置特征提高了效果。这个结论仅针对本次测试的 `AND p_y >= t_y` 规则，不能推广到所有可能的位置规则。

| 数据划分 | TP | FP | TN | FN |
|---|---:|---:|---:|---:|
| 验证集 | 697 | 35 | 155 | 42 |
| 测试集 | 340 | 33 | 72 | 26 |

测试集有 33 个 Up 区域被误判为 Fall，26 个 Fall 区域被漏判。Fall 区域占测试样本的约 77.7%，所以整体 Fall F1 较高并不代表负例误报较少；Up 区域误报率仍达到 31.43%。该数值以人体区域为单位，不能写成图像级误报率。

以下三个样例已查看原始图像。标注作为本次实验的真实类别；解释针对静态画面中的可见形态，不确认完整跌倒事件。

| 测试集图像名 | 标注 | 预测 | 像素宽高比 | 可见现象及规则局限 |
|---|---|---|---:|---|
| `529_png_jpg.rf.33cf1f2505fc68d373c0fce53a32a586.jpg` | up | Fall | 0.7260 | 俯视画面中的站立人物，其可见框已经超过阈值。摄像机视角使站立人物也可能有较宽的框。 |
| `a44_bmp_jpg.rf.11bbb2f2efb12e4325a7808726b5627b.jpg` | up | Fall | 0.5706 | 人物抬起一条腿并张开手臂，框变宽。规则无法区分姿态变化与跌倒状态。 |
| `a147_bmp_jpg.rf.bafdad44e89a2d2f721de15235a01a78.jpg` | fall | No Fall | 0.4953 | 人物位于地面，但身体在画面中的投影仍较窄、较长，框的宽高比未达到阈值。 |

完整错误清单位于 `runs/geometry/test_aspect_ratio_errors.csv`，包含原始图像标识、框编号、宽高比、中心位置、标注和预测。几何规则只能利用框的外形及位置，不能直接表示关节关系、身体接触地面情况或动作历史。

## 复现与产物

在项目根目录、正常安装的 Python 环境中运行：

```bash
pip install -e .
fall-geometry --config configs/geometry.yaml
# 也可以使用：
python -m fall_detection.geometry --config configs/geometry.yaml
```

使用已经保存的阈值重新评估：

```bash
fall-geometry --config configs/geometry.yaml --model runs/geometry/model.json
```

`model.json` 保存完整精度的阈值、类别映射、选参原则和验证输入指纹；`metrics.json` 保存混淆矩阵、指标、运行环境和计时范围；CSV 文件保存逐区域预测、错误、混淆矩阵及排除记录。生成的 `runs/` 产物遵循项目约定，不加入版本控制。

本次运行使用 Windows、CPU、Python 3.12.14、NumPy 2.3.5、Pillow 12.3.0 和 PyYAML 6.0.3。仓库现有 `.venv` 指向的 Python 3.14 基础解释器已不可用，本次使用可用的 Codex Python 运行时，并复用已有的纯 Python PyYAML、pytest 依赖完成运行与测试；没有修改 `.venv`。

计时只包含从已加载的框计算几何特征及输出预测，执行一次预热和 25 次测量，取中位数。当前测试集 471 个区域的宽高比预测约需 0.045 ms，总计时除以区域数约为 0.000096 ms/区域。该微型 CPU 测量可能随系统状态波动，不包含读图、读标签、人体定位、搜索阈值或写文件，不能直接与 YOLO 全图检测时间比较。具体本次计时以 `metrics.json` 为准。

测试覆盖非正方形图片的像素宽高比、阈值边界、F1 并列时 Recall 优先、二维搜索与独立穷举的一致性、空标注/无人排除、无效标签、测试标签不影响选参及冻结阈值复用。包含原有配置测试共 23 项，通过。

## 比较时需要保留的限制

几何规则收到正确的人体框，YOLO 则需要从全图定位目标。这里的区域级 F1 不能与已有 YOLO 的 mAP 直接比较，也不代表完整的跌倒检测系统性能。后续 HOG-SVM 应复用相同的人体区域和标签定义；YOLO 应另行完成报告规定的图像级 Fall/No Fall 评估。

本实验没有进行跨划分重复、近似重复或同一视频来源帧的检查，不能排除数据泄漏导致的乐观估计。图像标识、尺寸和标签的输入指纹用于复现实验，不能替代这一检查。
